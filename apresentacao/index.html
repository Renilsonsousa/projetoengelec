O que aparece no celular?

Ao escanear o QR, o usuário não entra no Portal administrativo da Engelec. Ele acessa uma página simples, referente somente àquele equipamento.

O usuário acessa somente a documentação liberada para aquele equipamento.Não tem acesso aos outros projetos, equipamentos ou documentos internos da empresa.

QR do QGBT-01Documentação liberada do QGBT-01
Endereço geral /documentos/Nenhuma lista de documentos

O endereço geral não funciona como uma biblioteca pública: sem o endereço específico daquele QR, não aparece uma lista com os documentos dos demais equipamentos.

Simulação conceitualOs nomes dos documentos são apenas exemplos visuais. A Engelec definirá quais documentos serão disponibilizados em cada caso.

Na prática, o que o Portal facilita para a Engelec?

O objetivo do Portal é fazer a informação seguir o mesmo caminho do projeto:

Do primeiro contato com o cliente até o painel entregue.
01Solicitação → Orçamento → Projeto

Menos trabalho repetido

Uma informação que já foi cadastrada pode seguir para a próxima etapa sem precisar começar tudo novamente.

02Um único ambiente

Mais facilidade para encontrar informações

Solicitações, orçamentos, projetos, equipamentos e documentos ficam organizados dentro do mesmo ambiente.

03Acesso por perfil

Comercial e técnico trabalhando com a mesma informação

Cada equipe acessa a parte que precisa, sem misturar informações comerciais com informações técnicas.

04Revisões e histórico

Mais segurança nas alterações

Quando uma proposta ou documento é atualizado, as versões anteriores podem continuar guardadas no histórico.

05QR Code no painel

Documentação mais fácil de consultar depois da entrega

O QR dentro do painel permite acessar pelo celular os documentos que a Engelec decidiu disponibilizar para aquele equipamento.

06Entrega

Uma entrega mais profissional para o cliente

Além do painel produzido, a Engelec oferece uma forma organizada e moderna de consultar a documentação disponibilizada.
